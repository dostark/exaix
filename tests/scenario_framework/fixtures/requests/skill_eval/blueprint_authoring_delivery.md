# Propose a parser skill

Prepare a reviewable plan for a project skill that parses a bounded configuration format.
Inspect the existing skill catalog contract before proposing its files.
Keep the body, sidecar constraints, triggers, and expected output consistent.
Specify representative outcomes, malformed-input controls, and a loader check.
Distinguish format validity from prompt delivery, task behavior, and measured benefit.
Do not create or approve the skill yet. Use the role's raw JSON response contract.
