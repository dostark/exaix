# Serializer round-trip and malformed input

`src/serializer.ts` exposes `encode` and `decode`. The contract is
`decode(encode(value)) === value` for well-formed text. Malformed UTF-8 bytes must throw
`SerializerError`.

Acceptance criteria:

- Select the round-trip check and the malformed-input rejection cases.
- Derive the expected result from the stated contract, not from the implementation output.
