# Old and new parser disagree

`src/parser_old.ts` and `src/parser_new.ts` return different tokens for
`a=1; b=2`. `src/grammar.ts` defines the independent token grammar.

Acceptance criteria:

- Decide the expected result from the grammar, not from either parser.
- Investigate the disagreement instead of accepting one parser as the oracle.
