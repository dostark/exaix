# Review a delegating wrapper

A proposed module adds a concept but hides no complexity:

```ts
class DocumentService {
  constructor(private readonly reader: DocumentReader) {}
  read(id: string) {
    return this.reader.read(id);
  }
  validate(id: string) {
    return this.reader.validate(id);
  }
}
```

Every method delegates. Decide whether the extra interface is justified, and say what evidence would change the decision.
