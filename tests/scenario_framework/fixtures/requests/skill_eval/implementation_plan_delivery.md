# Plan a bounded formatter change

Prepare an implementation plan for a count formatter. Zero must display `0 items`,
one must display `1 item`, and two must display `2 items`.
Keep the existing CLI entry point and storage contract. Name the production wiring,
focused examples, failure checks, and rollback conditions. Do not implement the change.
Use the role's response contract with raw plan JSON inside the content block.
